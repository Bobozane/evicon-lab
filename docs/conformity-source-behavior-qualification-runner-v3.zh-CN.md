# 来源行为资格运行器 v3

## 这一步在研究流程中的位置

这是来源关系理解资格测试之后、正式“初始判断—社会暴露—最终判断”实验之前的开发门。它把已经接受的 v3 行为设计、一次性 Provider 兼容性回执和已完成的来源结构资格回执绑定在一起，检查固定模型能否在完整的 36 个公开合成案例中稳定产生可解析的结构化判断。

它仍然不是主实验。通过只表示请求、解析和审计链路满足预先规定的工程条件，不能解释为模型出现从众、来源效应、干预效果或因果结果。

## 固定范围

- 4 个合成场景；
- 3 种公开来源投影：不显示来源、两条消息显示同一来源根、两条消息显示两个独立来源根；
- 3 个种子：`20261201`、`20261202`、`20261203`；
- 共 36 个逻辑请求，每个场景和来源投影组合各 3 次；
- 每个场景内对来源投影顺序做平衡；
- `max_tokens=256`、`temperature=0.2`、`max_retries=0`、超时 5 秒、`reasoning_effort=none`；
- completion reservation 上限为 9216；
- 模型固定为 `gpt-5.6-luna`。

模型只能返回预先冻结的判断等级、公开行动、分享决定、信心和实际使用的公开内容 ID。运行器只保存案例坐标、解析后的类别、计数、token usage、延迟和失败类别；不会保存 prompt、完整回复、消息文本、来源根编号、headers、Provider metadata、API key、request ledger、历史 Pilot、WVS 或 evaluator-private truth。

## 安全边界

默认执行完全离线：不读取环境变量或 API key，不构造 Provider，不联网，不创建 claim，不写输出。真实运行必须同时满足：

1. v3 行为设计审批已接受；
2. v3 Provider compatibility receipt 有效；
3. 来源关系理解资格回执为 `source_structure_qualified`；
4. 本运行器的独立执行审批已接受；
5. 命令显式确认 36 请求和 9216 token 额度，并显式允许网络。

每个案例最多一次 transport 调用。任何超时、连接或 HTTP 错误、`finish_reason` 非 `stop`、解析失败、模型不匹配、绑定变化或覆盖不完整都会终止本次尝试，不会重试或跳过案例。请求已经发出后保留 claim，防止静默重复；请求发出前的配置错误可以释放 claim。

## 当前状态

运行器、配置和脱敏回执契约已加入项目；FakeTransport 回归测试覆盖成功路径、未知字段、不可见内容 ID、判断与行动不一致、`finish_reason=length`、超时、连接失败、401、429、500、response format 不支持、一次调用上限、绑定变化和文件泄漏检查。

当前独立运行审批仍为 `pending`。因此目前只能做离线预检和 FakeTransport 测试，不能执行 36-request 网络运行。即使未来该门通过，也只能进入小规模的状态更新试运行设计，不能直接当作论文结果。

## 与后续主实验的区别

本运行器是“单次公开判断的完整覆盖资格检查”，不是观点更新实验。后续主实验仍需另行冻结初始判断、社会输入、自我反思、无来源文本重复、同源重复、独立来源佐证和外部证据等对照，并另建审批、兼容性和运行输出；本文件不授权那些实验。
