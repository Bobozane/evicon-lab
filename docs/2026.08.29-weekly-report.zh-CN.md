# 2026.08.29 周报：系统迭代、形成性预试与开题研究思路

## 一、本周工作概括

本周工作分为两个相互关联、但需要分别解释的部分：

1. 根据前两位参与者的反馈，调整系统流程、交互提示和研究记录方式；
2. 完成两位新参与者的形成性预试，目前累计完成 4 位参与者；
3. 在前期系统探索的基础上，进一步收敛计算机方向的开题研究问题，形成面向 AAMAS 的多智能体研究路线。

形成性预试的目的，是发现系统使用问题、角色互动的适用边界和可能的负面体验，不用于证明系统的普遍效果。后半部分提出的多智能体研究方案目前也是研究设计，不是已经得到的行为或因果结果。

## 二、系统迭代

根据前期反馈，本周对系统进行了以下调整：

- 将角色互动改为用户可以自主选择的环节，而不是强制流程；
- 增加对 A/B 纠结结构的确认，先确认用户是否确实存在需要比较的两种选择；
- 保留用户接受、修改或拒绝 AI 表达的机制；
- 增加暂停、跳过和现实信息核实等退出方式；
- 简化现实行动环节，减少与核心决策无关的操作负担；
- 优化页面提示、按钮层级和研究数据导出。

本周同时完成了交互系统的代码测试，当前 48 项自动化测试均通过。

从设计上看，系统正在从“让用户完成一套固定的角色互动流程”，转向“由用户决定是否进入互动，并对 AI 的表达进行校准”。这个变化是本周形成性预试直接推动的结果。

## 三、新增两位参与者的形成性预试

### P03：计算机专业师兄

P03 使用真实的“科技子公司 vs 省公司科技岗”选择进行体验。

使用前，P03 已经能够清楚说明两个选项的主要差异，初始倾向为 A，信心为 70%。使用后：

- 倾向变为“两边接近”；
- 取舍清晰度和理由清晰度均保持 7 分；
- 阅读与操作负担为 7 分；
- “导演感”（系统是否在引导用户朝某个方向走）为 3 分。

在角色互动中，AI 曾将“定居稳定”误解为“收入稳定”。P03 对这段表达进行了修改，明确指出自己真正关注的是工作地点，以及轮岗后能否回到成都。之后，他进一步形成了接受 B 的条件，包括收入、绩效、工作地点和生活节奏。

P03 的主要反馈是：

- 自己在进入系统前已经比较清楚 A/B 的边界；
- 角色化表达比较生硬；
- 自己扮演角色容易重复已经知道的内容；
- 互动增加了没有新信息的摇摆；
- 更希望 AI 把未知内容转化为现实中可以核实的问题。

### P04：产品经理方向师姐

P04 使用真实的“互联网公司 TOC 产品策划 vs 成长阶段 AI 数字化产品经理”选择进行体验。

使用前，P04 倾向 B，信心为 60%，取舍清晰度和理由清晰度均为 5 分。使用后：

- 仍然倾向 B；
- 信心、取舍清晰度和理由清晰度均未变化；
- 认为 A/B 取舍梳理比较有帮助；
- 认为角色互动产生了新的边界和可接受条件；
- 阅读与操作负担为 6 分。

在一次互动中，AI 将自主权表达为不可牺牲的底线。P04 拒绝了这段表达，并修改为：如果能够换来更好的工作生活平衡，她可以接受部分自主权减少。

这说明 P04 通过校准 AI 表达，进一步明确了自己的让步条件。但她同时认为：

- 角色命名最没有必要；
- 自己扮演角色比较麻烦；
- 角色化可能让原本可以共同考虑的因素看起来像是在互相冲突；
- 更希望 AI 将未知信息转化为现实核实问题。

## 四、四位参与者的初步发现

结合前两位参与者和本周新增的 P03、P04，目前可以得到以下形成性观察：

1. A/B 取舍梳理相对更稳定地被认为有帮助；
2. 用户接受、修改或拒绝 AI 表达的过程，可能帮助用户进一步精确自己的边界和可接受条件；
3. 角色命名和角色互动的作用并不稳定；
4. 对已经能够清楚表达 A/B 边界的用户，角色互动可能重复已有理由，或者增加不必要的负担；
5. 用户的变化不一定表现为倾向改变，也可能表现为边界、让步条件或第三种选择更加明确；
6. 系统仍需更好地区分“价值冲突”和“现实信息不足”；
7. 用户对 AI 表达的主动校准，可能比固定的角色互换本身更值得继续研究。

这些观察不能推出“角色互换无效”。更准确的说法是：角色互换的帮助具有条件性，且可能对已经形成明确判断的用户带来重复或负担；而 AI 表达的可修改性和现实问题转化功能显示出更稳定的研究潜力。

## 五、由形成性预试引出的开题研究思路

### 5.1 研究方向的收敛

在用户系统的形成性预试之外，计算机方向的研究主线正在收敛到 LLM 多智能体社会学习和信息传播。具体来说，计划搭建一个可控的离线多智能体信息传播实验和评测框架：让智能体先独立判断，再接收来源结构不同的社会消息或新的外部证据，并记录其实际暴露和判断变化。初步相关工作筛查表明，LLM 从众、多数意见影响、观点翻转原因分解和重复内容控制都已经有研究基础。因此，本研究不把“LLM 会从众”本身作为创新点，而是进一步研究来源依赖能否被严格测量和干预。

核心问题是：

> 在公开文本、消息数量和传播顺序相同的情况下，Agent 的观点变化能否被分解为基于新增证据的更新、对独立来源的合理采纳，以及仅由同源重复传播造成的盲目采纳？

这个问题的关键不只是“有多少条消息”，还在于消息最终来自多少个独立来源，以及 Agent 是否获得了真正新增的外部证据。

### 5.2 三类信息的区分

需要把以下三种情况分开：

1. **同源重复传播：** 多条消息最终都来自同一个原始来源，只是被不同 Agent 转发或改写；
2. **独立来源佐证：** 多条消息来自没有共同上游的不同来源；
3. **外部证据：** Agent 直接获得原始记录、测量结果或其他可检查的证据材料，而不是只听到另一名 Agent 的判断。

同源和独立描述的是社会消息之间的来源关系，外部证据描述的是是否出现了新的事实材料。它们应作为不同因素进行实验控制。

直观地说，同一个来源被多个 Agent 转发十次，仍然只算一个来源；两个没有共同上游的来源才算两份独立支持；直接提供原始记录或测量结果，则属于外部证据，不等同于社会消息的重复。

### 5.3 研究问题

**问题一：Agent 是否使用来源独立性？**  
在消息文字、数量和顺序相同的情况下，只改变来源关系，观察 Agent 的判断、信心和分享行为是否变化。

**问题二：如何区分社会重复和证据驱动的更新？**  
先记录 Agent 的独立初始判断，再分别给予无来源文本重复、同源消息、独立来源消息或外部证据，并设置无社会输入的自我反思基线，最后观察判断变化。

**问题三：来源感知干预是否能改善群体信息质量？**  
在多轮 Agent 网络中，比较无干预、普通异议、只看消息数量的策略和来源感知策略，考察错误级联、正确少数纠正和干预代价。

### 5.4 实验的基本结构

研究计划分为两层。

第一层是来源依赖识别：

- Agent 先形成独立判断；
- 再接受自我反思、无来源文本重复、同源重复、独立来源或外部证据；
- 最后重新判断；
- 比较判断、信心和分享行为的变化；
- 将“是否显示来源”与“来源是否独立”分别控制，避免把来源披露效应误认为独立性效应。

第二层是多轮网络实验：

- 多个 Agent 在网络中逐轮接收和分享信息；
- Agent 的分享决定下一轮其他 Agent 实际看到的内容；
- 同一来源被多次转发仍只算一个来源；
- 干预只能影响下一轮；
- 真实答案只在实验结束后的离线评估中使用。

计划覆盖四类合成场景：错误观点形成多数、正确少数纠正、独立来源形成正确共识，以及证据不足的未决争议。

### 5.5 相关工作定位与预期贡献

截至 2026 年 8 月 29 日的定向检索显示，已有研究分别讨论了 LLM 从众和多数意见影响（[Zhu 等，ACL 2025](https://aclanthology.org/2025.acl-long.195/)、[BenchForm，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/1da9ca7e9cef4b1af63913f05d1630a4-Abstract-Conference.html)）、自我不稳定与社会影响造成的观点翻转（[Hao 等](https://arxiv.org/abs/2606.00820)）、不显示说话者时的重复内容影响（[Hu 与 Qu](https://arxiv.org/abs/2607.05545)），以及有害采纳和有益纠正之间的权衡（[Qu 等](https://arxiv.org/abs/2606.01637)）。多智能体网络中的曝光和信念级联也已有近期研究（[Qiu 等](https://arxiv.org/abs/2608.25152)）。其中部分工作目前还是公开预印本，但在 2027 年投稿时仍应作为需要回应的相关工作。因此，本研究不主张首次提出从众现象、观点变化分解或无来源重复控制。

在目前查到的工作中，尚未看到同一个离线多智能体实验协议同时正交控制社会消息的来源根关系和外部证据输入，并用实际曝光记录与轮次回放审计确认 Agent 看到的内容，再检验来源感知干预对错误级联和少数纠正的双重影响。这个组合是当前最有希望的差异点，但仍需在投稿前继续核对论文全文、代码和实验材料，不能提前表述为已经证实的研究空白。

预期贡献不是再次证明“LLM 会从众”，而是：

1. 在已有从众和观点变化分解研究的基础上，加入可验证的来源依赖因素，将文本重复、同源社会传播、独立来源佐证和外部证据更新分开测量；
2. 提供能够核查每个 Agent 每一轮实际看到了什么的曝光记录和回放审计；
3. 检验按独立来源数量而不是消息数量判断信息支持程度的来源感知策略；
4. 同时评估错误级联抑制和正确少数纠正保留之间的权衡。

更适合论文的表述是：

> 本研究在已有 LLM 从众和观点变化研究的基础上，提出一个可审计的来源依赖社会学习评测与干预框架，在控制文本和传播量的条件下，将同源重复、独立佐证和外部证据分开，并检验来源感知策略对错误级联和少数纠正保护的影响。

## 六、当前项目进展

### 6.1 面向用户的交互系统

目前已完成：

- 角色互动可由用户自主选择；
- 用户可以接受、修改或拒绝 AI 表达；
- 增加暂停、跳过和现实核实出口；
- 完成 4 位参与者的形成性预试；
- 交互系统 48 项自动化测试通过。

目前形成的判断是：A/B 取舍梳理和 AI 表达校准较有潜力，固定的角色命名和角色互换作用不稳定。形成性预试仍然是设计研究，不是普遍效果验证。

### 6.2 面向计算机论文的多智能体研究

目前已完成：

- 来源追踪和来源根归并；
- 实际信息暴露记录和轮次回放；
- 公开视图下的干预框架；
- Agent 的结构化判断、采纳和分享接口；
- 新版来源行为资格协议的设计、离线测试和一次模型接口兼容性检查；
- 相关工作的初步定向筛查，并据此收窄研究的新颖性表述。

目前尚未完成：

- 新版来源行为资格协议的正式行为运行；
- “初始判断—社会暴露—最终判断”的多轮主实验；
- 外部证据的独立实验条件；
- 多模型、多网络结构和足够随机重复；
- 来源感知干预的效果和统计结论；
- 相关论文的系统性全文、代码和实验材料核查。

两条线目前不应合并统计：用户形成性预试用于发现交互和设计问题，多智能体实验用于回答来源依赖和社会学习问题。二者的共同启发是，不能只用“选择是否改变”作为唯一结果，还应记录边界、条件、信心和不确定性是否变得更清楚。

## 七、需要与导师讨论的问题

### 7.1 用户系统的研究主线

本轮结果尚未显示角色互换具有稳定、普遍的帮助。不同参与者的反馈存在差异：部分参与者通过互动形成了新的边界，另一些参与者则认为互动重复、生硬并增加负担。

需要确认：

- 是否继续以角色互换为主要研究对象；
- 是否将重点调整为“用户如何校准 AI 角色表达，并形成更准确的价值边界和可接受条件”；
- 是否冻结当前版本并继续招募参与者；
- 是否将“现实核实问题生成”作为新的功能重点。

### 7.2 计算机论文的研究范围

需要确认第一篇论文的范围：

- 以来源依赖的测量和审计框架为中心；还是
- 同时纳入完整的来源感知干预实验。

还需要进一步确认研究定位和必要对照：

- 论文是否明确定位为“来源依赖的可审计测量与干预”，而不是声称首次研究 LLM 从众；
- 是否把无社会输入、自我反思和无来源文本重复作为必要对照，而不是把它们表述为本研究独有的创新。

前者研究范围更稳健，能够先验证问题是否可测；后者贡献更完整，但需要更多模型、网络结构、随机重复和基线比较。

5. 在获得导师确认和单独授权前，不扩大真实网络实验。

## 九、本周汇报结论

本周的主要进展不是得到一个“角色互换有效”或“角色互换无效”的结论，而是明确了系统的适用边界：用户更稳定地受益于取舍梳理和对 AI 表达的主动校准，角色命名和强制角色互动则可能重复已有思考或增加负担。

同时，初步相关工作筛查表明，从众现象、观点变化分解和重复内容控制本身已有前人研究。因此，计算机方向的开题问题进一步收敛为：在 LLM 多智能体社会网络中，能否把同源重复传播、独立来源佐证和外部证据分开测量，并通过可审计的实际曝光和轮次回放，检验来源感知策略是否能够减少错误级联、保护有证据支持的少数纠正。

下一步应先冻结研究定义和实验测量，再决定是否扩大参与者研究或进入多轮网络主实验。当前所有形成性预试、资格测试和兼容性检查都不构成普遍行为效果、因果效果或论文结论。
