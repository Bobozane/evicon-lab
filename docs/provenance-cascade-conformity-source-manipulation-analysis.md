# Source-Manipulation Gate Analysis

This is a read-only, evaluator-only audit of the completed source-root
manipulation qualification gate. It binds the gate configuration, v3 timeout
resume amendment, safe resume receipt, and append-only request ledger by
SHA-256.

The gate verifies an operational precondition only: a response must match the
two *already visible* public source-root relations supplied in its context. It
does not measure adoption, sharing, attitude change, source credibility, or a
causal behavioral effect. The analysis therefore reports transport completion
and case-coordinate coverage, not a behavioral result.

The ledger intentionally excludes prompts and raw responses. Accordingly, the
analysis labels individual parsed response outcomes as not observable from the
safe artifacts, even though the completed gate receipt proves that its bounded
execution terminated successfully. This is a deliberate audit limit, not a
license to infer source-sensitive behavior.

Any next behavioral source-manipulation study must use a new, versioned
protocol and preserve safe per-case semantic outcome facts (case ID, public
projection, parser status, and aggregate decision counts) without saving raw
responses. It must remain isolated from WVS studies and all earlier cascade
pilots.
