# EviCon-Lab 研究思路汇报（导师版）

**日期：** 2026-08-29  
**研究方向：** LLM 多智能体系统中的社会学习、信息级联与来源感知干预  
**拟投稿方向：** AAMAS 2027

## 一、研究背景

LLM Agent 越来越多地被用于讨论、协作决策和社会模拟。在多 Agent 环境中，一个观点被多个 Agent 重复表达时，其他 Agent 可能把“很多人都在说”理解为“存在多份独立证据”。但这些消息可能只是对同一个原始来源的转发和改写。

这带来一个基本问题：

> 当 Agent 改变观点时，它究竟是在根据新证据进行合理更新，还是仅仅因为同一信息被社会网络重复传播而盲目采纳？

现有研究已经发现 LLM 会受到多数意见、权威标签和其他 Agent 回答的影响，也已经出现一般性的反思或异议干预。因此，本项目不把“发现 LLM 会从众”作为创新点，而是关注一个更具体的问题：多 Agent 系统能否区分同源重复和独立佐证，并对这种区别进行可审计的测量和干预。

## 二、核心研究思想

本研究的核心判断是：

> 消息数量不等于证据数量。判断一条信息获得了多少支持，不仅要数有多少条消息，还要追溯这些消息最终来自多少个独立来源。

例如，两名 Agent 都说“某项检测不合格”，可能有三种情况：

1. 第二名 Agent 只是转发第一名 Agent 的消息，两条消息实际来自同一来源；
2. 两名 Agent 分别获得了独立测量结果，属于两个独立来源；
3. Agent 除了听到社会消息，还直接看到了可以检查的原始记录或证据。

这三种情况下，表面的“支持数量”可能相同，但合理的观点更新程度不应该相同。

## 三、研究问题

### RQ1：Agent 是否真正使用来源独立性？

在消息文本、消息数量和呈现顺序相同的情况下，只改变来源关系：不显示来源、显示同一来源、显示多个独立来源。观察 Agent 的判断、信心、采纳和分享行为是否发生变化。

### RQ2：如何区分社会重复和证据驱动的观点更新？

先记录 Agent 在没有社会信息时的独立判断，再分别给予：自我反思、无来源文本重复、同源社会消息、独立来源消息或外部证据，最后记录其判断变化。

这样可以将普通的不稳定性、文本重复、社会来源和新证据的影响分开。

### RQ3：来源感知干预能否改善群体信息质量？

在多轮 Agent 网络中，比较无干预、普通异议、只看消息数量的干预和来源感知干预，研究其能否：

- 减少由同源重复造成的错误级联；
- 保留有独立证据支持的少数纠正意见；
- 避免对真实的独立共识进行不必要干预；
- 将干预成本和误报控制在合理范围内。

## 四、实验设计

研究分为两个层次。

### 第一层：来源依赖识别实验

每个实验单元先产生一个独立初始判断，然后进入不同的信息条件：

| 条件 | Agent 获得的信息 | 主要作用 |
|---|---|---|
| 独立初始判断 | 不看 Peer 消息 | 建立个人基线 |
| 自我反思 | 重新思考但不看 Peer | 测量模型自身不稳定性 |
| 无来源文本重复 | 看到重复内容，但来源不显示 | 测量文本重复效应 |
| 同源重复 | 多条消息显示为同一个来源 | 测量同源社会重复效应 |
| 独立来源 | 相同数量消息显示为多个独立来源 | 测量独立佐证效应 |
| 外部证据 | 直接看到原始记录或证据材料 | 测量证据驱动更新 |

所有条件尽量保持主张、文字内容、消息数量和顺序一致，只改变研究所需的来源关系或证据暴露。

需要特别控制“是否显示来源”这一因素。正式实验应将“来源是否显示”和“来源是否独立”分别操控，避免把来源披露效应误写成来源独立性效应。

### 第二层：多轮网络干预实验

将第一层中验证有效的测量方法放入一个小型多 Agent 社交网络：

- 每个 Agent 先独立判断；
- Agent 可以采纳、拒绝、保留意见并决定是否分享；
- 分享行为决定下一轮其他 Agent 实际看到什么；
- 同一来源经过多次转发仍只算一个来源；
- 干预只能在下一轮生效；
- 真实答案只在实验结束后的离线评分中使用。

计划覆盖四类合成场景：

1. 错误观点形成表面多数；
2. 少数 Agent 提出有证据支持的正确纠正；
3. 多个独立来源形成正确共识；
4. 证据不足、合理行为应是保持不确定。

## 五、核心假设

### H1：来源独立性敏感性

在文本和消息数量相同时，多个独立来源应比同一来源的重复传播带来更强、更合理的观点更新。

### H2：同源重复的级联风险

当来源关系不可见时，同源消息在网络中的重复传播可能被误认为多个独立支持，从而放大错误采纳和继续分享。

### H3：来源感知干预的保护作用

来源感知干预应当比普通异议或只看消息数量的干预更有选择性：它既减少同源错误级联，也更少压制有独立证据支持的少数纠正和正确共识。

## 六、主要评价指标

研究不会只统计“大家最后是否一致”，而会同时关注：

- 错误观点的采纳和传播；
- 有证据支持的少数纠正是否被保留；
- Agent 是否愿意接受真正的新证据；
- 同源重复导致的错误方向改变；
- 干预是否错误地作用于正确共识或合理分歧；
- 来源多样性、级联规模和传播深度；
- 实验回放是否通过；
- Token、延迟和干预成本。

统计时以“场景 × 随机种子”作为主要重复单位，不把同一网络中的多个 Agent 当作彼此独立的样本。

## 七、预期贡献

本项目预期形成三方面贡献。

### 1. 测量贡献

提出一种将自我不稳定、文本重复、同源社会传播、独立来源佐证和外部证据更新分开的实验设计，避免把所有答案变化都笼统称为从众。

### 2. 多智能体系统贡献

建立逐 Agent、逐轮记录真实信息暴露的实验框架，使研究者能够核查 Agent 当时究竟看到了哪些消息、来源和证据，以及分享和干预如何改变后续传播。

### 3. 干预贡献

研究一种按独立来源数量而不是消息数量判断信息支持程度的干预策略，并同时评估“减少错误级联”和“保护正确少数纠正”之间的权衡。

更适合论文的总体表述是：

> 本研究提出一个可审计的来源依赖社会学习评测与干预框架，在控制文本和传播量的条件下，将同源重复、独立佐证和外部证据分开，并研究来源感知策略对错误级联和少数纠正保护的影响。

## 八、当前进展

目前已经完成：

- 来源追踪、实际暴露记录、轮次回放和公开/私有信息隔离的实验底座；
- Agent 的结构化判断、采纳和分享接口；
- 无干预、普通异议、来源盲和来源感知四种干预框架；
- 离线评分指标；
- 新版来源行为资格协议的设计、离线测试和一次模型接口兼容性检查。

历史小实验主要完成了工程验证，也暴露了测量任务不可识别、有效样本不足和条件分离不明显等问题。这些旧结果已经隔离，不作为论文结论。

目前尚未完成：

- 新版来源行为资格协议的正式行为运行；
- 具有“初始判断—社会暴露—最终判断”的主实验；
- 外部证据的独立实验条件；
- 多模型、多网络结构和足够随机重复；
- 干预效果和统计结论。

因此，项目当前处于“测量与审计基础完成，主实验待实现和执行”的阶段，而不是“实验结果已经得到”的阶段。

## 九、主要风险及应对

| 风险 | 可能后果 | 应对方法 |
|---|---|---|
| 模型不使用来源信息 | 后续网络实验无法识别来源效应 | 先做小规模资格测试，不通过则修改材料 |
| 模型只对来源标签形式作反应 | 测到提示捷径而不是真实来源判断 | 使用不透明来源编号、平衡顺序和隐藏/显示对照 |
| 外部证据与社会消息混在一起 | 无法区分合理更新和从众 | 将证据作为独立对象和独立条件投递 |
| 控制器间接知道场景答案 | 干预效果近似预设答案 | 控制器只读取公开消息、来源和证据状态 |
| 可分析单元不足 | 指标大量不可计算 | 真实运行前模拟每条最小暴露路径并设置阻断条件 |
| 单模型、单网络结构 | 结论难以推广 | 后续增加模型、随机种子和网络拓扑 |

## 十、下一步计划

1. 固定主实验的初始判断、最终判断、来源条件、外部证据条件和指标定义；
2. 在完全离线环境下完成新版运行器和全流程模拟；
3. 小规模运行来源行为资格测试，判断模型是否真正使用来源关系；
4. 若资格测试通过，再进行一个模型、少量种子的多轮网络试运行；
5. 修正协议后扩展到多模型、多种子和多个网络结构；
6. 完成干预比较、统计分析和论文撰写。

当前最需要导师讨论和确认的问题是：第一篇论文应以“来源依赖的测量与审计框架”为中心，还是同时纳入完整的来源感知干预实验。前者范围更稳健，后者贡献更完整，但需要更大的实验规模和更严格的基线比较。

## 十一、阶段性判断

这个研究问题表面上是“让 Agent 看不同的来源标签”，但真正要解决的是多智能体信息传播中的一个基础测量错误：多个相关联的社会报告经常被当作多份独立证据。

如果能够证明传统的消息数量或答案翻转指标会混淆同源重复和独立证据，而来源追踪和逐轮暴露审计能够纠正这一问题，那么项目的价值不只是一个提示词实验，而是一套面向 LLM 多智能体社会学习的评测方法和干预依据。

当前最合理的研究策略是先保证“能正确测量”，再讨论“干预是否有效”。
