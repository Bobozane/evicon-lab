# Protocol-Blind v2 Test Scenario Authoring

This is a preparation artifact for a future confirmatory study. The test scenario is an original synthetic English task with a new scenario ID, decision options, evidence chronology, and evidence cards distinct from the development scenario. It is not a WVS item, benchmark, or real-world claim.

The authoring metadata records provenance and a local SHA-256. A separate researcher review file must confirm that the scenario is independent of development material, safe synthetic content, and appropriate for protocol-blind use. Until that review is accepted, the confirmatory gate remains `blocked`.

No provider, prompt, API key, result directory, or real model is used by this stage. A later real execution still requires its own explicit network, request, token, and run confirmations.
