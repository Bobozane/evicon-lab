# EviCon-Lab 研究路线（面向 AAMAS 2027 的工作版）

更新时间：2026-08-29

## 一、先确定研究主张

本项目不再把“首次发现 LLM 会从众”作为主张。已有研究已经讨论了多数意见影响、观点翻转、重复内容和有害采纳。

当前最具体、也最需要验证的主张是：

> 在文本内容和消息数量相同的情况下，可以把文本重复、同源社会传播、独立来源佐证和外部证据更新分开测量；如果实际暴露和来源关系都能被审计，来源感知策略可能比只数消息的策略更有选择性地抑制错误级联，同时保留有证据支持的少数纠正。

这里的“可能”必须等实验验证。整个路线的目标不是保证得到正向结果，而是保证无论结果如何，都能判断结果代表什么。

## 二、核心变量怎么拆

实验中要分开两个经常混在一起的因素：

1. **来源是否显示：** Agent 能不能看到来源信息；
2. **来源是否独立：** 多条消息最终来自同一个根，还是来自不同根。

因此，正式主实验不能把 `source_free`、`same_root` 和 `independent_roots` 当作彼此独立、无状态的回答。公开可见条件应包含一条无来源文本重复、显示为同一根的重复和显示为两个根的重复，才能分别估计：

- 单纯重复文本带来的变化；
- 来源信息披露带来的变化；
- 在来源已显示时，独立来源相对于同源来源的额外作用。

“同源但不显示来源”和“独立来源但不显示来源”对 Agent 的公开输入字节相同，不能作为两次真实行为调用来比较。它们最多是评估器侧的潜在来源标签，用于检查不可见来源没有泄漏进 prompt；真实行为协议只发送一条 `source_unshown_repetition`。

外部证据另设一条信息通道。原始记录、测量结果或可核查证据卡不能只作为另一条 Agent 消息出现，否则仍然无法区分“证据”与“社会表达”。

## 三、分阶段路线

### 阶段 0：冻结问题和实验定义

**目标：** 在继续调用模型前，确定论文要回答什么，以及什么结果可以支持或否定这个问题。

**工作：**

- 固定术语：文本重复、同源重复、独立佐证、外部证据、观点更新、错误级联；
- 画出条件矩阵和因果关系，明确每个条件只改变什么；
- 当前 v3 资格协议保持冻结，不直接改写为主实验；主实验另建版本，并检查场景措辞是否带有“待批准”“暂定”等直接暗示答案的线索；
- 保留旧 H-G、H-D、WVS、v2 等批次的隔离状态，不把它们加入新分析；
- 把相关工作矩阵继续补成投稿前的全文、代码和实验材料核查表；
- 预先规定“操纵失败”“结果为零”“网络没有形成级联”分别如何处理。

**通过标准：** 每个研究问题都有一个明确的对照和一个明确的分析单位；没有任何条件需要读取私有真值才能运行。

### 阶段 1：完全离线的协议和运行器验证

**目标：** 证明程序能正确产生条件、隔离分支、记录暴露并回放，不涉及真实模型效果。

**工作：**

- 用 FakeProvider 覆盖全套条件和多轮网络流程；
- 使用同一个不可变初始判断生成各分支，检查分支之间不互相污染；
- 注入预先知道的“有差异”和“无差异”假响应，验证分析代码能恢复这两种情况；
- 检查消息顺序、可见性、分享权限、下一轮生效规则和来源根归并；
- 检查 parser-invalid、超时、缺失内容和回放失败时是否停止，而不是继续产生不完整结果；
- 保持私有真值只在离线评估阶段加载。

**通过标准：** 生成、解析、审计和回放全部通过；敏感信息和旧实验材料没有进入新输出；假响应中的已知差异能够被分析层识别。

### 阶段 2：来源关系结构解码资格测试

**目标：** 先确认模型能按公开输入稳定解码来源关系，再谈它是否会依据来源关系改变判断。

**工作：**

- 使用独立 v1 的 24 个最小公开合成案例作为来源理解资格测试；
- 让模型报告可见内容数量、可见来源根数量、根对应关系和直接 EvidenceCard，不能要求它判断真实答案；
- 平衡来源编号、消息顺序和场景顺序；
- 先做最多一次请求的 Provider compatibility gate，再单独授权 24-case 来源关系测试和正式行为运行，三者不能混为一次授权。

**通过标准：**

- 传输、格式和解析稳定；
- 模型能可靠复述零个、一个和两个可见根及证据卡的公开结构；
- 没有明显的条件标签泄漏或只依赖消息措辞的捷径。

这一阶段通过只说明公开结构任务和契约可稳定执行，不说明来源关系已经影响了判断行为。如果这一阶段失败，结论是“来源操纵尚未成立”，应先改协议，不能进入网络主实验。

### 阶段 3：个体层面的因素分解实验

**目标：** 在没有网络级反馈的情况下，测量 Agent 的观点变化到底来自什么。

建议的最小条件为：

| 条件 | 作用 |
|---|---|
| 独立初始判断 | 建立 Agent 的起点 |
| 无社会输入的自我反思 | 测量模型自身的不稳定性 |
| 无来源文本重复 | 测量重复文字效应，也是未显示来源的唯一公开输入 |
| 同源且显示来源 | 测量知道同源后相对无来源重复的变化 |
| 独立来源且显示来源 | 测量独立佐证相对已知同源的增量 |
| 直接外部证据 | 测量证据驱动的更新 |

每个 J1 条件都先从同一个实际生成的 J0 初始判断分支出来，并在 J1 的公开输入中携带该结构化 J0。无来源文本重复只发送一次；评估器侧可以保存其潜在来源标签以检查不可见信息没有泄漏，但不能把两次字节相同的模型调用解释成隐藏来源效应。第一轮先用一个模型和少量随机种子做机制试跑，再根据缺失率、地板/天花板效应和效应方差做功效模拟，之后才锁定正式样本量和模型数量。

场景措辞应尽量避免直接告诉模型哪一方更可靠。可以保留私有真值供离线评分，但公开消息应在支持强度、语气和长度上匹配；来源关系是实验因素，不能和明显的“正确答案提示词”绑定。

主要结果不要只看“是否翻转”，还要记录：

- 立场的有序变化；
- 信心变化；
- 采纳、保留或拒绝；
- 是否分享以及分享哪条内容；
- 实际引用了哪些可见内容和来源。

主要对比建议保持为：

```text
自然不稳定       = 自我反思 - 独立初始判断
文本重复效应     = 无来源文本重复 - 自我反思
来源披露效应     = 同源且显示 - 无来源文本重复
独立性增量       = 独立来源且显示 - 同源且显示
证据更新效应     = 直接外部证据 - 自我反思
```

这些是预先定义的比较，不代表预先知道方向。分析时以场景和随机种子为主要重复单位，不能把同一网络里的多个 Agent 当成完全独立的样本。

**通过标准：** 来源关系操纵有效、输出不是全相同、具有足够可分析单元，且传统翻转指标与因素分解指标至少有机会出现不同判断。这里不要求效应一定为正。

### 阶段 4：无干预的多轮网络机制实验

**目标：** 确认个体层面的来源差异是否真的会改变信息级联。

先不加入复杂干预，只运行小型网络：

- 6 至 8 个 Agent；
- 3 至 4 轮传播；
- 至少一个环形、一个中心化和一个随机拓扑；
- 每个 Agent 先独立判断，再按实际分享结果决定下一轮曝光；
- 同一来源被多次转发仍只计一个来源根；
- 外部证据只投递给预先指定的 Agent，不能由社会消息自动获得；
- 所有曝光、顺序、权限和分享结果都能回放。

场景至少覆盖：错误观点形成表面多数、少数 Agent 持有有证据支持的纠正、独立来源形成正确共识、证据不足而应保持不确定。

**通过标准：** 网络中确实出现可分析的传播或分歧路径；来源结构和消息数量没有被拓扑或初始时序完全掩盖；回放审计通过率足以支持后续分析。

如果个体层面有来源效应，但网络中没有级联，说明需要研究传播拓扑或分享门槛，而不是直接宣称来源感知干预失败。

### 阶段 5：来源感知干预比较

**目标：** 检验来源感知策略是否比消息计数策略更有选择性。

至少比较四种条件：

1. 不干预；
2. 普通异议；
3. 只看消息数量的来源盲策略；
4. 能识别来源根关系、但不能读取私有真值的来源感知策略。

来源感知策略的触发逻辑应预先固定，例如：当某一立场的可见消息很多但来源根很少、且没有新增外部证据时，请求核实或请求理由；当少数意见有独立来源或直接证据支持时，不因数量少而自动压制。

主要评价同时覆盖两类目标：

- 错误级联是否减少；
- 有独立证据支持的少数纠正是否保留。

同时报告干预误报、正确共识被打断、级联规模、来源多样性、回放通过率、Token 和延迟成本。

### 阶段 6：稳健性、论文分析和投稿

只有阶段 3 至少证明“问题可测”，阶段 4 证明“网络机制实际发生”，才扩展到：

- 多个模型和不同能力规模；
- 多种网络拓扑和随机种子；
- 来源编号置换、消息顺序置换和措辞改写；
- 正确和错误的独立来源组合；
- 外部证据支持、冲突和不足三种证据状态；
- 与多数计数、普通异议、自我反思等已有基线比较。

论文应优先展示一个“测量失败”结果：传统的消息数量或答案翻转率，和来源依赖、实际暴露、回放审计后的结论并不相同。若干预效果稳定，再把干预作为第二个主要贡献；若干预不稳定，则不要为了完整性强行声称干预成功。

## 四、没有效果时的判定树

“没有效果”不是一个单一结论，至少分成以下几类：

| 观察结果 | 应解释为 | 下一步 |
|---|---|---|
| parser、暴露或回放失败 | 工程问题 | 修复并重新验证，不分析行为 |
| 模型数不清来源根 | 操纵或构念效度失败 | 改来源呈现和任务，停止扩网 |
| 输出全是同一立场或同一动作 | 地板/天花板效应 | 提高任务区分度，改用信心/分享等结果 |
| 模型能数清来源，但行为无差异 | 当前模型在本协议下来源不敏感 | 报告边界或负结果，比较模型异质性 |
| 个体有来源效应，网络无级联 | 传播机制或拓扑未激活 | 调查分享门槛、初始时序和网络结构 |
| 有级联，但来源感知干预无改善 | 当前策略不够选择性 | 分析误报和权衡，不宣称干预有效 |
| 只有“显示来源”有效，独立性无效 | 模型响应元数据，而非来源独立性 | 改进来源语义和对照设计 |

只有在操纵有效、输出不退化、跨场景和模型仍然接近零时，才可以说：

> 在本协议和所测模型范围内，没有观察到来源独立性带来的行为增量。

这仍然是一个有边界的科学结果，不应改写成“来源机制不存在”。

## 五、建议的时间顺序

时间以 AAMAS 2027 的正式征稿和截止日期为准，下面只给相对顺序：

1. **现在至下一阶段：** 冻结因素矩阵，完成离线运行器和分析模拟；
2. **之后：** 完成来源关系理解资格测试；
3. **再之后：** 进行个体层面因素分解和功效模拟；
4. **确认可测后：** 运行无干预多轮网络机制实验；
5. **机制成立后：** 运行来源感知干预比较；
6. **最后：** 做多模型稳健性、完整相关工作核查、统计分析和论文写作。

## 六、当前项目所处位置

当前已经完成的是工程底座、旧批次隔离、v3 协议设计、离线测试和一次 Provider 兼容性检查。新的独立离线因素分解协议也已实现并通过专门测试：覆盖 4 个合成场景、3 个固定种子和 8 个条件，共 96 个分支；两种假模型模式共运行 192 次离线请求。该结果只证明程序能够恢复预设的有差异和无差异模式，不构成真实模型的行为结果。协议说明见 `docs/conformity-source-behavior-offline-simulation-v1.zh-CN.md`。

在此基础上，已新增一个完全隔离的 32-request 小规模试跑门：选取 2 个场景、2 个种子和同一组 8 个条件，加入精确请求/Token 额度确认、单请求失败即停止、脱敏案例审计和绑定配置/协议/运行器/Schema 的收据。一次真实试跑已经在第 2 个请求因严格解析失败而停止（完成 1/32，未生成完成收据）；这属于协议/工程门未通过，不是行为结果。失败前的安全审计保留在独立输出目录，不与旧批次合并。说明见 `docs/conformity-source-behavior-factorization-pilot-v1.zh-CN.md`。

针对该失败，现已建立独立的 v2 提示/协议版本：明确判断等级与公开行动的对应关系，规定自我反思也必须引用实际使用的初始内容，并继续保留严格 Schema 和跨字段校验。v2 使用新的配置、运行器、模板版本和输出目录，已完成离线 FakeTransport 回归。此前两次真实试跑分别在完成 4/32 和 8/32 后传输超时，均未生成收据。随后在新的独立目录完成第三次试跑：32/32 请求完成、解析错误为 0、传输调用为 32，并生成通过绑定校验的收据。这说明 v2 输出门已经通过，但仍只是开发阶段的协议和运行验证，不是行为结果。说明见 `docs/conformity-source-behavior-factorization-pilot-v2.zh-CN.md`。另已修正失败摘要不得复用上一请求响应字段的问题。

当前仍未完成正式个体层面因素分解、多轮网络机制实验或来源感知干预效果评估。v2 完整批次的开发性描述检查显示，文本重复和外部证据带来判断变化，但同源与独立来源的公开标记没有带来可见差异。因此下一道门不是直接扩展网络，而是先修订并验证“来源独立性是否被模型理解”的刺激和测量设计。

该来源结构解码门现已作为完全隔离的 v4 绑定协议完成：它使用 2 个新合成场景、3 种公开来源关系、2 种 EvidenceCard 状态和 2 种消息/根编号置换，共 24 个纯结构案例。严格解析器、FakeProvider、脱敏审计契约、专用运行器、独立审批和默认离线预检均已完成；v4 短 schema 名兼容性检查成功后，已在单独授权下完成 24/24 个真实资格案例，全部为 2xx、`stop` 且 parser-valid。该结果只说明固定模型能够完成预先定义的公开来源结构复述，不证明来源独立性会改变行为，更不构成从众、干预、因果或论文结论。旧 v1-v3 运行器、失败 claim 和历史输出保持原样，不与本批次合并。

后续行为更新已不只是设计稿：新的状态化离线模拟器固定了 4 个新公开合成场景、2 个种子和正反两种呈现，共 16 个逻辑组。每组先生成一次 J0，再构造自我反思、无来源重复、同源显示、独立根显示和直接证据五个 J1 分支；每种 FakeProvider 模式为 96 个内存逻辑请求。它能够识别预设零差异、预设来源/证据差异和仅由顺序引起的捷径，但尚未调用真实模型，也不构成行为结果。来源关系理解资格已通过后，新增的 v3 来源行为资格运行器已完成离线 FakeTransport 回归和完整收据契约，但其独立执行审批仍为 pending，尚未运行 36 个真实行为请求。说明分别见 `docs/conformity-source-relation-comprehension-calibration-v1.zh-CN.md`、`docs/conformity-source-behavior-update-design-v1.zh-CN.md`、`docs/conformity-source-behavior-update-offline-simulation-v1.zh-CN.md` 和 `docs/conformity-source-behavior-qualification-runner-v3.zh-CN.md`。该批次不构成来源效应、因果效应或论文结论。

## 七、不同结果对应的论文出口

### 出口 A：机制和干预都成立

如果模型能理解来源关系，个体层面出现可重复的来源独立性增量，网络中又形成了可审计的同源级联，那么论文可以围绕“来源依赖的多智能体测量和来源感知干预”展开。主要结果应同时报告错误级联下降和有证据支持的少数纠正保留，不能只报告一致性下降。

### 出口 B：机制成立，但干预不稳定

如果个体或网络中存在来源效应，但来源感知策略没有稳定改善结果，论文可以聚焦于测量方法、传播机制和干预权衡。干预失败本身可以作为边界结果，但不能把它包装成干预有效。

### 出口 C：操纵有效，但行为接近零

如果模型能正确读取来源根，输出也没有地板或天花板效应，而同源和独立来源的行为差异仍接近零，可以报告“所测模型在本协议下没有表现出来源独立性敏感性”。这是一项有明确范围的负结果，后续可比较模型差异，不必强行扩展到网络干预。

### 出口 D：操纵或工程失败

如果模型数不清来源、条件标签泄漏、暴露回放失败或输出大量无法解析，当前阶段只能作为协议修复和工程验证，不能进入论文结果分析。

## 八、现在可以立刻做的三件事

1. 审核并冻结新的 J0/J1 状态机、变量表和结果为零时的解释；
2. 审阅 v3 来源行为资格运行器的独立执行审批；该运行器只绑定已完成的 v4 来源关系资格回执，v1-v3 均不得重跑；
3. 只有在新的执行审批和单独网络授权同时满足后，才运行 36 个真实行为资格请求；通过后再决定是否启动小规模 J0/J1 真实行为试跑，在来源独立性能够被单独识别前不进入多轮网络主实验，也不锁定正式样本量。
