# Protocol-Blind v2 Confirmatory Gate

The confirmatory manifest is a future planning contract, not an execution command. It requires at least three new seeds, four explicit conditions per seed, a manually reviewed test scenario independent of the development scenario, the frozen English v2 ProbeSet, and the fixed primary metrics `pairwise_diversity`, `social_influence_loss`, and `profile_drift`.

The current template is intentionally blocked: it has no accepted test scenario and no run declarations. The new synthetic English test scenario has its own authoring record and independent human review record; a manifest must bind its path, ID, and SHA-256 to those reviewed materials. The `003` calibration and condition-aware v1 `002` pilot are excluded from confirmatory statistics. Any future real execution must add a separate explicit network, budget, and researcher confirmation gate.
