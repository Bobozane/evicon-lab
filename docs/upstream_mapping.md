# Upstream Mapping and Code Boundary

## Policy

EviCon-Lab is independently implemented. Upstream work may inform research
questions, protocols, terminology, and evaluation design, but no source code,
prompt text, data, or generated artifact is imported unless its license,
attribution obligations, and compatibility are verified before use.

| Reference work | Intended use in EviCon-Lab | Reuse status | Required boundary |
| --- | --- | --- | --- |
| MultiAgent-Diversity | Diversity and repeated social-exposure baseline design | Local reading and method reference only | No code or derived code; licensing status must be independently resolved before any reuse. |
| Easier-to-Mislead-Than-to-Correct | Harmful versus beneficial update framing | Local reading and method reference only | No code or derived code; licensing status must be independently resolved before any reuse. |
| ProMediate | Mediation task framing and intervention evaluation ideas | Reference only in Phase 1 | Verify license before any implementation reference; retain notices and attribution for permitted reuse. |
| Social-Conformity-in-Large-Language-Models | Conformity protocol and statistical-method reference | Reference only in Phase 1 | Independently implement protocol and analysis; record any copied non-code asset separately. |
| ASVO | Value-driven agent and social-motivation modeling concepts | Reference only in Phase 1 | Independently implement models and prompts; verify license before reuse. |
| CASCADE | Influence propagation, verification, and recovery concepts | Reference only in Phase 1 | Independently implement metrics and recovery logic; verify license before reuse. |
| Agent-Kernel | Social simulation runtime-control concepts | Reference only in Phase 1 | Independently implement runtime interfaces; verify license before reuse. |

## Provenance record for future work

Before introducing external material, add a provenance record containing the
upstream repository or publication identifier, revision or version, license
text or authoritative license URL, material category, notices to retain,
EviCon-Lab files affected, and reviewer/date. A citation alone is not a reuse
authorization.

## Non-goals for Phase 1

This repository contains no vendored upstream source, submodule, dataset,
prompt collection, model output, benchmark result, or license claim on behalf
of any upstream project.
